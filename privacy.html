PRINT TODAY 개인정보처리방침

시행일: 2026년 10월 30일

1. 접근하는 정보

사용자가 직접 연결한 Gmail 계정에 대해 Google OAuth 범위 https://www.googleapis.com/auth/gmail.readonly만 요청합니다. 앱은 읽지 않은 메일의 보낸 사람, 제목, 수신 시각과 계정의 이메일 주소만 읽습니다. 메일 본문과 첨부파일은 읽지 않습니다.

2. 사용 목적

읽은 정보는 오직 사용자의 Mac에서 인쇄 미리보기를 만들고, 사용자가 지정한 프린터로 종이 한 장을 출력하는 데에만 쓰입니다.

3. 저장과 전송

  • 메일 정보는 서버로 전송되거나 외부에 저장되지 않습니다. 개발자를 포함한 제3자는 이 정보를 받지 않습니다.
  • 로그인 갱신 토큰은 사용자 Mac의 키체인에만 저장됩니다.
  • 메모와 인쇄 시각 기록은 사용자 Mac의 앱 데이터 폴더에만 저장됩니다.
  • 광고, 분석, 추적 도구를 사용하지 않습니다.

4. 쓰기 권한 없음

앱은 메일을 보내거나, 삭제하거나, 읽음 표시·라벨 변경 등 어떤 수정도 하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

PRINT TODAY가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 연결 해제와 삭제

앱 설정에서 계정을 삭제하면 키체인의 토큰이 지워집니다. Google 계정의 타사 앱 액세스에서도 언제든 권한을 철회할 수 있습니다.

Privacy Policy (English)

PRINT TODAY requests only the gmail.readonly scope for Gmail accounts the user connects. It reads the sender, subject and received time of unread messages, plus the account's email address; it does not read message bodies or attachments. This data is used solely on the user's Mac to render and print a single page. Nothing is transmitted to any server or third party, including the developer. Refresh tokens are stored only in the macOS Keychain; memos and print timestamps only in the app's local data folder. No ads, analytics or tracking. The app never sends, deletes or modifies mail. PRINT TODAY's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Remove the account in the app or revoke access at myaccount.google.com/permissions. Contact: GitHub Issues.
