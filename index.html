PRINT TODAY

PRINT TODAY는 개인용 macOS 앱입니다. 다음 날 하루를 종이 한 장으로 출력해 시스템 다이어리(A5 6공 리필)에 끼워 쓸 수 있게 해 줍니다.

  • 연결한 Gmail 계정에서 읽지 않은 새 메일의 보낸 사람과 제목
  • macOS 캘린더(iCloud)의 일정
  • 앱에서 미리 써 둔 날짜별 메모

Gmail은 읽기 전용(gmail.readonly)으로만 접근하며, 메일을 보내거나 삭제·수정하지 않습니다.

개인정보처리방침 (Privacy Policy)

PRINT TODAY is a personal macOS app that prints the next day's unread Gmail senders/subjects, calendar events and a memo onto a diary refill sheet. It accesses Gmail read-only and never sends, deletes or modifies mail.
